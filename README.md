# 🐍 Ejercicios de Desarrollo de Algoritmos en Python

Este repositorio contiene una serie de ejercicios prácticos desarrollados en Python para la comprensión de los fundamentos de programación.

## 📂 Contenido del Repositorio

* **`sintaxis_basicas.py`**: Ejercicios iniciales de sintaxis y estructura general de un programa en Python.
* **`variables.py`**: Prácticas sobre declaración, asignación y tipos de datos en variables.
* **`operadores.py`**: Uso de operadores aritméticos, lógicos y de comparación.
* **`condicionales.py`**: Implementación de estructuras de control condicionales (`if`, `elif`, `else`).
* **`ciclos.py`**: Uso de bucles y estructuras repetitivas (`while`, `for`).
* **`errores.py`**: Prácticas de manejo de excepciones y depuración de errores.
* **`integrador.py`**: Proyecto integrador que combina múltiples conceptos aprendidos.
